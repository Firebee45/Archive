# SSF - Most Full Checker
![cover](assets/media/area_render_54_.png)

Version: java
Tags: SSF, Cart

Sorts pairs of carts into most full and least full signal strength equivalent fill level

## Features
- Can only handle carts in 86gt+ internals
- Red output is most full output and that cart will be sent first.

## Downsides
- Gold heavy
- Both carts being checked need to be checked at the same exact gt

## Notes
ROTATION NOTE: This can be rotated in all 4 cardinal directions, however it will only work consistently if the carts are dropped into the starting tail from above with no X or Z velocity
