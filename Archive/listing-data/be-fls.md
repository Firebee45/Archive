# 8gt Fill Level Sorter V1.0

![cover](assets/media/area_render_130_.png)

Version: Bedrock
Tags: Storage, Box Processing

Splits boxes into full, part full and empty.

## Features
- 8gt (hopper speed - 9,000 items/h)
- Can be FHL

## Downsides
- Full output as a buffer 

## Notes
When loading the structure the sorter will break in many places. Please ensure it's chunk aligned and fixed according to the world download.
