# 8x8x8 Kelp Farm
![cover](assets/media/area_render_18_.png)

Version: Java
Tags: Farm, Crop, Plant

An 8x8x8 kelp farm for OneChunk

## Features
- 175/h
- 1 hopper

## Downsides
- has a disc based timer so music can be heard when running

## Notes
2 sides need to have a hall behind them (in the case of Onechunk this is the world border)
