# SSF - Merger
![cover](assets/media/area_render_147_.png)

Version: java
Tags: SSF, Storage, Cart, Encoded, Cart Tech

Merges two carts of the same item type together into the most full output

## Features
- FHL
- 4x Merging per module
- Semi fill level sorted output

## Downsides
- Gold heavy
- big
- kinda slow cart checking logic

## Notes
ROTATION, this only works facing North or South in the schem its facing North
