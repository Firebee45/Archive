# IMYSSC Main Storage V1.2
![cover](assets/media/area_render_132_.png)

Version: Bedrock
Tags: Storage, Main Storage

This storage is aimed at the more casual player.

## Credits
- Prepusio: For the chest hall used.  [Original post](https://discord.com/channels/764146345161392178/1294393364975849522/1297732450184859685)
## Features
- Fast unloading via Var UA
- Chest hall, bulk and overflow storage
- 50 Furnace array
- Hopper locking (not FHL)

## Downsides
- Has to be chunk aligned
- Bulk box collection isn't fully slice preserving

## Notes
When loading the structure the sorter will break in many places. Please ensure it's chunk aligned and fixed according to the world download. The structure is mainly there to be used to make a holoprint or strcutura
