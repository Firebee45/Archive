# SSF - 8 Bit Encoder
![cover](assets/media/area_render_12_.png)

Version: Java
Tags: SSF, Cart Tech, Encoded

An 8 bit  item encoder for SSF

## Features
- Only two static entities when not running (locked hopper carts)
- Can be FHL
- Auto loops
- Auto stop
- Easy set across

## Downsides
- 80-100 second encoding time
- Big
- Gold heavy

## Notes
The encoder sends its output as a pulse per bit. It also needs a jump start due to how it’s intended to be used.
