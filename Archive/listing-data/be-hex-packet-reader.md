# Hex Packet Reader V1.0

![cover](assets/media/area_render_126_.png)

Version: Bedrock
Tags: Storage, Encoded, Box Processing

Reads music discs in boxes and outputs the redsonte signal.

## Features
- 8gt per disc read
- Can be FHL
- Reloads packet
- Entityless when not running

## Downsides
- No auto read it needs a "read box signal"

## Notes
When loading the structure the sorter will break in many places. Please ensure it's chunk aligned and fixed according to the world download.
