# SSF - Merger Array
![cover](assets/media/area_render_44_.png)

Version: java
Tags: SSF, Storage, Cart, Encoded

Merges carts of the same item type to their most full output

## Features
- FHL
- 4 Mergers
- Fill level sorted output
- Auto start
- Fill level optimised input

## Downsides
- Gold heavy
- Can not be rotated
- Can not auto stop
- Can not recycle carts sent when all mergers are full
- 600 gt minimum input for pairs of carts
