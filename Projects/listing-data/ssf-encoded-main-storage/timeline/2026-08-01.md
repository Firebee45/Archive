## Update

**CONTEXT**

SSF is an abbreviation of Structureless Superflat, meaning this storage can only be made from things obtainable in a superflat world with no structures this means no stone, lava, nether etc etc. everything has to be abstained through mob drops, villagers* (only some are able to be gotten), and the wandering trader. 

This storage aims to prove A) what’s possible and B) push the limits as far as they can go while also ending up with a nice storage in the end. I’ve already made a few key components so I’ll show / explain those now. Another thing to note is this has to be made in spawn chunks (which I added back as I disagree with removing them, so I’m limited to a 3x3 entity ticking and 5x5 redstone ticking area..
