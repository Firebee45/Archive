So the core features:

- remote calling from bulk/NSS 
- remote sending to MS 
- p2p calls and sending for farms or anything else for that matter 
- bulk restocking, if low on supplies start up farms to refill that item, if it needs crafting use the universal crafting array (or dedicated crafters if beneficial) 

Implementation of these features are pretty universal between them, data transfer will be done via wireless redstone. Item transfer will use a nether network or instant bolts. Bulk monitoring will depend on how the bulk is made so those ho hand in hand with each other.

- world management, remote mob swing control, automatic bot player movement via piston bolts or something to send them to farms that require them. 
- dedicated systems for common items. Eg a redstone component factory to mass craft them in bulk faster then a uni array
- in theory even stuff like running quarries automatically is possible.
